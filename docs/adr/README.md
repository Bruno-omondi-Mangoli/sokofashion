# Architecture Decision Records

An ADR is a short document that records one important decision: the situation, the decision, and what we gave up. Number them in order. Never edit an accepted ADR. If a decision changes, write a new ADR and mark the old one as superseded.

## Template

- Title
- Status: proposed, accepted or superseded
- Context: what problem we faced
- Decision: what we chose
- Consequences: what becomes easier and what becomes harder
